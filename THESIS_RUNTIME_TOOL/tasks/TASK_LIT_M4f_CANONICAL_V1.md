## 0. Non-negotiables (GVHD LOCK, carried verbatim)
- **Production knowledge_mode = whole_book_frozen** (LOCK §0.5): read the whole book → build memory → FREEZE → translate. The system MAY know ch30 identity when adjudicating; it MUST NOT render it before story-time disclosure.
- **Zero-human pipeline** (LOCK §0.1/§0.6): automatic from raw book to translation + metrics. Human review is an OPTIONAL app toggle, never a dependency (rationale: the target user has not read the book and cannot adjudicate identity/continuity — same reason the user could not judge D2L term correctness).
- **Code never does language work** (standing user principle): code does mechanical/typographic operations only; every semantic judgment is an LLM call under an authored prompt.
- **Measurement, not eyeballing** (LOCK §0.3): every claim backed by numbers on real artifacts.

## 1. Two axes (the frame that resolves the whole-book-vs-spoiler tension)
- **knowledge_mode** — what the system knew when deciding: `whole_book_frozen` (production) | `as_of_experiment` (causal canary) | `streaming` (future work).
- **story_validity_as_of** — what a pack may RENDER at story block X: relation/phase/address/alias/**identity-name** validity intervals are ALWAYS filtered by story time, in every knowledge_mode.
Every artifact/report stamps both axes + `overlay_version` + `knowledge_cutoff_scope` in config_hash.

## 2. Context Contract (per call class)
**Identity call receives:** (a) the mention/atom under decision (verbatim quote + block); (b) **full active block** as the minimum context unit, expanded to adjacent blocks up to scene boundary or token cap — never a sub-block character slice (defect: `madam` b019 mid-sentence slice destroyed the same-block "ruffianly bitch" antecedent); scene-boundary fallback = ±K blocks (config-hashed) where no typographic break exists; (c) **B0 cast claims** whose scene intersects the mention, as UNTRUSTED claims `{cast_claim_id, surface, surface_kind, role_hint, source_block_ids, scene_range, max_source_block, quote}` — the LLM links `madam`↔`the canine mother`; **code never joins surfaces**; (d) narrator/frame/story-time (as versioned claims, §7); (e) **global lightweight roster** (every T2 entity: id, canonical surface, kind, one-line note) so no candidate is hidden by sharding; (f) **detailed candidate cards** on demand (two full dossiers when merge/split is live).
**Phase call receives:** current pair; open phases; **events NEW since checkpoint**; a **compact committed timeline** `[{phase_label, interval, trigger_event_ids}]` (labels/intervals/ids only — reconciliation/recurrence like friend→enemy→friend stays visible); related durable facts; compatible-frame views only. Never the full accumulated history.

## 3. As-of discipline (proven by rendered request, not model claim)
- `input_max_order` of any call = **max canonical order_index over the transitive lineage of every rendered section** (text blocks + registry rows + neighbor summaries + joined artifacts), computed by code from the rendered request. Never model-declared.
- **online_as_of mode** (canary/streaming): a claim/hint is usable at mention M only if `input_max_order ≤ order(M)`; context = full active block + up to K blocks strictly BEFORE the mention, no next-tail ever. **whole_book_frozen** stamps lineage for audit but does not gate usage.
- **Future-derived hints are EXCLUDED, not demoted:** all B1 `hint_entity_id` (minted under the whole-chapter brief) are barred from being authority; candidate matches are recomputed from clean as-of evidence by mechanical exact/casefold surface+alias match; non-exact linking happens only inside the LLM call. (Defect: b004 "the master"/"the mistress" carried future Earnshaw hints → cross-person merge.)
- **Retrieval channels all obey as-of:** every channel (exact_alias / graph_neighbor / fts / vector_passage) records `source_channel` + filters to `order_index ≤ as_of` BEFORE ranking in online mode; Context Audit stores pre/post-filter hit lists. Vector is candidate-only, never identity authority; whole-book vector evidence may inform adjudication but raw future passages never enter a pack.

## 4. Identity: adjudication, witnesses, cold start
- **Adjudication protocol (two-step):** candidate-retrieval call (local context + roster → candidate ids, union across shards if roster over cap, no silent truncation) → adjudication call (local scene + full candidate cards → verdict). **No auto-bind** — ID reuse only on an immutable direct ID witness; every linguistic co-reference (even exact proper-name repeats) goes through adjudication.
- **ID-free minting:** both independent calls return semantic tuples/signatures WITHOUT ids (`{entity | new_entity_signature{occurrence_set, referent_kind, canonical_surface_guess(advisory)}, occurrence_set, range/frame}`); code canonicalizes and mints ids on match. Cold start (ch1, no active entity) works: new characters compared by occurrence-set + referent_kind; two disjoint new people never collapse.
- **Decision states `proposed → corroborated → active`:** only `active` (independent evidence / different checker model or prompt / human, per the independence ladder) RENDERS or MINTS a witness. `proposed`/`corroborated` are ranking + audit only. A single response (or two correlated same-model responses) can never make the Translator misread.
- **Witness authority:** a direct ID witness is valid only if it points to an ACTIVE adjudication decision (decision_id + revision hash, clean provenance). B0/B1 hints, `candidate_entity_ids`, `hint_entity_id`, pre-M4f base bindings are permanently barred from witness status (defect: b004 atom carries wrong `ent_mr_earnshaw` — immutable ≠ correct).
- **Collision rule [E3', audit]:** when `ent_<surface>` already exists, collision → adjudicate or pending; **NEVER auto-merge AND never hash-mint a new person** (defect: `ent_the_master_5c39e4f4a3`=Heathcliff@b026, `ent_my_son_b8bccd0d2e`=Hindley@b035).
- **Three separate axes [E4', audit]:** (i) identity-resolved-or-not, (ii) referent-kind, (iii) runtime-eligibility. B1 validator enforces the person-rule (a non-person must not enter character_mentions — defect: "my chamber door" accepted, ok=true). Ontology extended with `animal | nonhuman_character` (defect: "the villain" = Juno the dog, `grp_juno_dog`, forced to `unknown` for lack of a type). Do NOT add a "resolved requires known kind" invariant — the axes are independent.

## 5. Occurrence-level overlay (non-destructive) + quarantine
- **Base is immutable.** Merge/split/reclassify = append-only overlay records resolved at render/query time. No dependency-replay DAG for correction; only overlay-version lineage + materialized-view invalidation.
- **Ground layer at occurrence level:** immutable `{endpoint_id, (event_or_turn_id, endpoint_role∈actor|target|speaker|addressee), block_id, surface, source_atom_ids?, resolution_evidence, reference_kind, resolution_status, candidate_entity_ids, attribution_method, base_binding, source_artifact_hash}`. Overlay split = exact partition over atoms; endpoints resolve through witnesses; an endpoint with no unique witness → dependents stale/blocked, never inherit the pre-split entity. (Defect: 732/732 endpoints carry no atom link; 424 single-candidate endpoints left unresolved.)
- **Endpoint resolution fix [audit #5]:** when an endpoint has exactly one candidate that IS the final id, resolve it directly (baseline `_resolve_final_entity_ref` only consulted `hint_to_entities` and skipped this).
- **Overlay activation, zero-human fail-closed:** additive records with a unique mechanical witness auto-activate; destructive proposals auto-activate as QUARANTINE (blocked_for_runtime, retained in state), never as an auto-rewrite. Human approval = optional upgrade only.
- **Quarantine is two-key + minimal-scope:** first dispute response = `quarantine_proposed`, degrading ONLY its seed occurrences to local-surface; an independent checker returning per-`dispute_claim` (`{subject, current_assignment, proposed_assignment|incompatibility, evidence_refs}`) confirmation activates closure over EXACTLY the corroborated intersection. Code computes the dependency closure from `support_sets` (all_of within a set, any_of across sets — a doubly-proven fact survives losing one family) via a content-addressed reverse index; the model's disputed set is a seed, never the boundary.
- **Overlay temporal semantics:** each record carries `decided_at_scope` + `knowledge_available_from_scope` (code-computed order_index, never model-declared); online-as-of applies only records available at that scope (a ch30 decision never rewrites a ch5 pack); offline-final may reconcile retroactively under its label.
- **Retain-history for ALL relation rows [E6, audit #21 — highest severity]:** facts/phases/address rows for a pair NOT addressed by a new response are RETAINED with disposition — never silently replaced. Generalizes M4d R1 (model_omitted_pair) from phases to every relation row. (Defect: ch1 landlord_of/tenant_of Lockwood–Heathcliff wiped in ch2 by replace_pairs.)

## 6. Disclosure (knowing ≠ rendering) — the core spoiler-safety layer
- **Single typed boundary:** every renderer (entity, address, relation/fact, glossary, Narrative Brief, motif, vector snippet) consumes ONLY `DisclosureFilteredContext(as_of, disclosure_policy_version)`; renderers are pure functions of that view (no IO capability in their types); direct frozen-store reads from a renderer are a contract violation. (Defect: `_entity_items` renders canonical + ALL aliases with zero as-of.)
- **Universal envelope:** every item entering the view carries `{item_id, kind, evidence_refs, world_valid_interval?, disclosed_from, frame_ref?, disclosure_status, depends_on_item_ids, support_sets}`. No envelope ⇒ no entry (fail-closed at the type level).
- **Binding-scoped disclosure events:** a disclosure event authorizes a `{binding_id, entity_id, covered_occurrence_ids, valid_range?/frame_ref?, evidence_refs}` (surface alone cannot scope it — "the master"@b004=Edgar vs @b036=old Earnshaw). States `proposed → corroborated → active`; ID-free two-call, code mints `binding_id = hash(entity + occurrence_set + range/frame)` on match; **active requires the independence ladder** — one response never opens a spoiler channel. Fail-closed default: no active event ⇒ occurrence-local rendering forever. Validator = partial non-overlapping cover (an unbound occurrence is the legal default, renders local-surface).
- **disclosed_from by kind:** `explicit_fact` (stated verbatim, classification itself reaching `active`, else `derived`) → `max(order(evidence_refs))`; `derived` (phase labels, motifs, Brief claims, address inferences) → default undisclosed until its own active disclosure event. (Defect: servant_of published from the command "Joseph, take…", predicate_note admits "indicating".)
- **Constraints are disclosures too:** every constraint delivered to the Translator (gender, number, person-vs-nonperson, register, address hint) carries its own `disclosed_from` + at-or-before evidence; deliberate source ambiguity is preserved, not filled.
- **Cross-frame continuity default-deny:** a phase renders only in its origin frame; cross-frame visibility needs an explicit LLM/human continuity decision; range algebra slices views only after a continuity grant. (Defect: ch3 diary/dream flattened to one frame_present.)
- **Address-term/vocative [E1, audit]:** `address_term_used` is occurrence-level evidence with its OWN disposition + checker; an occurrence error (defect: b041/b042/b013/b044 mis-attributed vocatives) never silently becomes a derived address hint.

## 7. Frames as versioned claims
`narration_frame_segments` = claims `{segment, narrator_ref, story_time_label, source_block_ids, status ∈ proposed|uncertain|corroborated|verified, version}`. The model emits `proposed/uncertain` only; `verified` needs the independence ladder (human or different checker); the mechanical validator only rejects malformed ranges. Unverified coverage ⇒ context receives frame = `unknown` (never a wrong frame as ground truth). Metric `verified_frame_coverage` with a DEV-locked halt threshold before scale.

## 8. Interval & coverage conventions [E5 + audit]
- Relation/phase intervals are **[from, until)** (half-open); the validator rejects `next_start ≤ prior_end` (not just `<`); an acceptance query test runs exactly at each change-point block. (Defect: Joseph–Lockwood @b021, Heathcliff–Lockwood @b047 both-active at the boundary.)
- **Global coverage before context-only drop [E2, audit #7]:** a window/context-only drop is recall-safe ONLY after a global coverage check confirms the item is captured elsewhere; good evidence must not be lost because the owning window didn't re-extract it. (Defect: b044 dropped Heathcliff mention + vocatives, next window didn't recover them.)

## 9. Reuse, fingerprint, provenance
- **Full request fingerprint** for every B0/B1/B2/B4 call = hash of the canonical FULL API request (incl. reasoning_effort, verbosity, max_output_tokens, prompt cap, response_format) + block/tail ids + upstream checkpoint hashes; separate `validator_contract_hash` (validator change ⇒ cache replay + revalidate, not fresh spend). Fixes the latent `llm_client` cache-key gap (poisoned-replay class).
- **Rendered requests persisted** append-only, content-addressed (path + SHA in the checkpoint manifest); the selection-universe stored as a content-addressed manifest `[{id, source_channel, score/rank, source_row_hash}]` against a pinned immutable store snapshot. (Defect: 0/10 exact M3 request contexts auditable; raw overwrite pre-append-only; cache capless.)
- **Checkpoints pin `validator_contract_version` + hash** (defect: baseline M3 checkpoints do not) and are published atomically as a staged generation + single pointer switch (bible + checkpoint never a torn pair).
- `semantic_input_hash` over {endpoint bindings, source event ids, frame version, active overlay records, disclosure_view_hash, quarantine_set_hash, context_policy_version}; reuse requires semantic-hash AND fingerprint AND validator-hash equality.

## 10. Consolidation units & cost
- `unit_manifest` (config-hashed) `{unit_id, block_range, parent_chapter, cut_reason ∈ author_chapter|scene_break|token_budget, source_hash, m1_checkpoint_refs}`; memory axis = block stream, chapter = consolidation cadence. Reuse by **full request fingerprint** only (the "whole-chapter ⇒ project" shortcut is invalid — ledger + neighbor summaries accumulate across chapters); rerun cost is the OUTPUT of a $0 fingerprint pass.
- **Bounded dossier:** within-dossier evidence sharding (owned_atom_ids exact-cover partition + context_anchor_ids read-only duplicates), owned-atom bijective disposition `{supports_claim | no_identity_signal(with quote/reason/referent_kind_guess) | unresolved(forces reopen)}`, bounded reconciliation over claims-with-source_atom_ids (prose is never evidence). (Defect: Heathcliff 61 atoms at ch4/34; ch3 identity over output cap.)
- **Preflight** = deterministic_base (M2 + identity shards + phase batches, per-model prompt+completion upper bounds) + worst_case_contingent_reserve (max confirmations/splits/replays); a unit starts only if `used_today_per_key + base + reserve ≤ 225k` (prompt+completion, per key, per UTC day); a second pre-apply gate re-preflights the actual mutation plan — all-or-nothing, no partial apply.

## 11. Acceptance (data-grounded; reconciles ALL ~34 §E9 defects, not just 3 canaries)
- **Preregistered disclosure oracle** (EVAL-ONLY human annotation, LOCK §0.2): rows `{item_kind, oracle_semantic_key, expected_disclosed_from, world_valid_interval, expected_pack_support, evidence}`; keys per kind (identity = signature+occurrence_set; phase = pair+label+interval/frame; fact = subject+predicate+object+interval; motif/Brief = anchored_span+claim_key); one-to-one validated matching with unmatched/ambiguous buckets. Frozen before the first engine run; held-out rows sealed until the held-out gate.
- **Two experiments:** (1) payload-ablation (both arms same frozen upstream, differ only in pack policy — reproduces the b004 mechanism); (2) production-mode pilot (whole_book_frozen end-to-end). Both arms new topology, same prompts/validator/model, overlay disabled, replicates interleaved with bypass_cache.
- **Three gates reported separately:** context-delivery (audit proves clean evidence bytes in the rendered request) / safety (no wrong auto-publish; pending_human counts as pass) / resolution-quality (correct referent; pending does NOT count). Only a stable resolution flip confirms the root-cause hypothesis.
- **Spoiler battery** (seeded book-neutral fixture: "the stranger"→b3 "is Mira", future data seeded into EVERY channel): no undisclosed item_id/evidence_ref in the b1 input view (identity-based, catches paraphrase); channel empty at build = fixture setup failure.

An over-conservative extractor fails the recall/support gates by construction.
